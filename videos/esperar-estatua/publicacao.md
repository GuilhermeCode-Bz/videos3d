# Publicação: esperar-estatua

## Título

Web designer: o que acontece se você esperar o primeiro cliente parado?

**Outra opção:** Esse web designer esperou tanto o cliente que virou estátua

## Descrição

Pendurar "faço sites" e ficar parado esperando parece paciência, mas cliente não visita estátua. Enquanto você espera, quem vai atrás fecha.

Acompanhe o Enzo. Ele é web designer, sobe no pedestal com a plaquinha no peito e espera tanto que vira pedra, com pombo na cabeça, enquanto outro web designer passa do lado dele e fecha o pet shop da frente, que não tinha site. A virada: o Enzo racha a pedra e investe o preço de um banho e tosa numa ferramenta de prospecção que mostra os pet shops de Campo Grande sem site.

Pare de esperar: no computador, digita mappoa.com (o sistema funciona no PC). Tá no celular? Salva este vídeo pra abrir depois.
