# Publicação: leilao-de-freela

## Título

Web designer: você ainda briga por cliente no preço?

**Outra opção:** Oitenta web designers disputando o mesmo cliente

## Descrição

Site de freela e grupo de Facebook viram um leilão: oitenta web designers, um cliente só, e ganha quem cobra menos.

Acompanhe o Caio. Ele é web designer e disputa cada projeto levantando a plaquinha do preço, até perder pra quem fez por R$ 150. A virada: ele larga a plaquinha, para de brigar e vai onde ninguém está. Com um sistema de prospecção, acha as óticas de Aracaju que precisam de site e chega sozinho, sem leilão.

Ache quem precisa de você na sua cidade: no computador, digita mappoa.com (o sistema funciona no PC). Tá no celular? Salva este vídeo pra abrir depois.
