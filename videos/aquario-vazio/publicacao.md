# Publicação: aquario-vazio

## Título

Web designer sem cliente: você tá pescando no lugar errado?

**Outra opção:** Onde achar cliente pra fazer site (não é no grupo de web designer)

## Descrição

Você manda "faço sites" pra quem já tem site e pra grupo cheio de web designer, e nada morde. O problema não é a isca. É o lugar.

Acompanhe o Léo. Ele é web designer e passa o dia jogando a isca num aquário vazio, enquanto outro web designer joga a rede no rio e puxa uma barbearia. A virada: o Léo troca de lugar e decide investir o preço de um corte de cabelo numa ferramenta de prospecção que mostra as barbearias de João Pessoa sem site, com quem mais precisa do serviço dele.

Pesque onde tem peixe: no computador, digita mappoa.com (o sistema funciona no PC). Tá no celular? Salva este vídeo pra abrir depois.
